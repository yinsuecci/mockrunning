Route Studio · Mac 版

1. 解压 ZIP，把整个 Route-Studio 文件夹放到“下载”等可写入位置。
2. 双击“启动 Route Studio.command”。第一次需要联网，会自动安装 Python 和依赖；等终端显示本地地址并打开浏览器。
3. 浏览器地址：http://127.0.0.1:8765 。这是你自己电脑上的界面。
4. 将用于开发测试的 iPhone 用 USB 连接电脑，解锁并信任电脑，按手机提示启用开发者模式。在网页选择并连接设备。
5. 保持运行服务的终端窗口打开。结束时先在网页停止/断开手机，再回到终端按 Control+C。

支持 Apple Silicon（M 系列）与 Intel 的安装脚本架构选择。本次验证平台为 Apple Silicon Mac；没有完成 Intel Mac 真机验证。建议使用仍受支持的较新 macOS。

如果 macOS 阻止打开：先尝试在 Finder 中右键脚本，选择“打开”。如系统要求，可在“系统设置 → 隐私与安全性”按系统提供的提示允许该脚本。不要关闭系统安全保护。
如提示没有执行权限，在终端输入 chmod +x 后加一个空格，把“启动 Route Studio.command”拖进终端，然后回车；再双击。

第一次安装需要访问 GitHub 和 PyPI，下载可能需要几分钟。失败后可重新双击启动，或运行“安装或修复 Route Studio.command”。安装工具、Python 和依赖放在此文件夹的 .runtime 和 .venv 中，不需要管理员密码。
此 ZIP 不含预装 Python 或依赖，约几百 KB；首次安装后磁盘占用会增加。

地图需要联网，主底图失败会尝试备用底图。地图不可用时，坐标输入、GPX 导入和回放仍可用。
定位连接需要手机的开发者服务可用；网页能打开不代表手机一定兼容。此工具不替代真机陀螺仪或加速度计。
