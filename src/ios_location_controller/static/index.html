    02 / DEVICE PLAYBACK

    在手机上回放

    支持 iOS / Android，USB / 无线。连接手机并导入数据后，自动设置到起点。

    连接方式
    连接已建立的可信 Wi-Fi RSD 隧道；隧道须持续运行。首次配对通常需要 USB。
    首次无线配对（Android 11+）配对端口与连接端口不同，配对码不会保存。

    iPhone 需要已信任电脑且开发者服务可用。

    精度是显式测试参数，不是真实测量。双源使用同一条测试路线，但精度与更新节奏独立；未替换的真实源可能与测试坐标冲突。

    当前连接只模拟定位，不改写陀螺仪、加速度计或卫星原始数据。

    尚未连接定位服务
    USB 发现与定位服务连接是两个不同状态。
    未载入路线
    输入地点并切换定位
    搜索结果来自 OpenStreetMap。切换不会修改路线；运行路线时请先暂停或停止。
    运动参数
    0 为关闭；建议从 1–3 米测试。每圈更新节点，闭合路线跨圈连续；与左右波动叠加。

    运动中参数锁定；暂停后可调整并继续。随机种子和坐标点随机半径须停止后重新开始才生效。波动仅用于定位测试，不代表真实人体运动。
